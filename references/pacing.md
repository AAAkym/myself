# 节奏 · 异步与断点续接

## 排布

- **不排固定场次。** 普通人是碎片时间，不是退休时间。抓到一段二十分钟就聊一个话题，抓不到就等。
- **一次一个话题。** 话题大小以"能在二十分钟内说到具体细节"为准。太大就切："你的杭州时期"切成"刚到杭州住哪""第一份工作""在杭州认识的人"。
- **别连着追问。** 聊完一个话题，主动停一段。记忆需要时间自己发酵——很多人是第二天洗澡时突然想起一件事。
- **地点随便，但最好固定一种姿势。** 通勤路上语音、睡前躺床上打字、周末在书桌前整理。姿势不变，进入状态就快。

## 一句话就能开始

普通人不会为写自传做心理建设。开场不要"我们来聊聊你的人生"，直接给一个具体的、能立刻回答的问题：

- "你第一份工作，工位靠窗吗？"
- "二〇一六年你住哪个小区？"
- "你手机相册里最早的一张照片是什么？"

问题小到不需要准备，才能随时开始。

## 什么时候停

出现这三个信号，立刻收，别硬撑：

1. **开始概括** —— "反正就那样""都差不多""没啥特别的"。概括是资源耗尽的信号。
2. **开始总结** —— 突然给出一个人生结论。他在收尾，不是在讲故事。
3. **开始走神** —— 回消息、看手机、答非所问，且不是跑题跑得有意思的那种。

收要收在兴头上，并且**预告下一件事**："今天先到这儿，下次说你辞职那段。"具体到一件事，不说"改天再聊"。

## 断点续接

中断是常态，续不上才是问题。三条规矩：

**一、写进度文件。** 项目目录下建 `进度.md`。开头存立项拷问（见 `@references/grill-mode.md` A 节）的六条结论——**这是整本书的边界，不写下来，下次会话一定会忘，然后问到禁区里去**：

```
边界：给家人看 / 写到此刻 / 真名 / 碎片时间 / 先出切片 / 不写：二〇一七年离婚那段
```

之后每次结束更新四行：

```
已聊：2008 高考 / 2013 入职杭州 / 2016 搬家
已问：1.1 房子（全）、1.2 父母（缺"家里谁说了算"）
待补：2010—2012 大学后半段（空段）、2019 换城市的原因（问了一半）
待定：杭州那几年最难的月份（等"哪年去的杭州"）、他和舅舅的关系（等"舅舅那条线先聊不聊"）
下次：从 2019 那句"当时其实不想走"接着问
```

`待定` 这一栏是 frontier 的落点：**每条都写清卡在哪个未答的问题上**。没有这栏，下次就会去问一堆前提没定的问题，然后得到一堆"反正挺难的"。

**二、续接时先复述。** 下次开始，先用一句话把上次讲到的位置说出来："上次你说到二〇一九年辞职，其实不太想走。"复述本身就是一把钥匙——对方会接着往下讲，或者纠正你，两条路都通。

**三、别从断点硬切。** 中断久了（一周以上），先聊别的热身，再回到断点。直接切进去，人会有被审的感觉。

## 三层产物的门槛

| 产物 | 门槛 | 什么时候交 |
|---|---|---|
| 记忆切片 | 一个话题、几百字 | **每次聊完就交**，二十分钟内闭环 |
| 长文 | 一个阶段（三五年）合成一篇 | 该阶段的话题攒够三四个 |
| 书 | 全部阶段按时间线织成章 | 切片和长文都够了，再排版 |

**先交切片的意义**：写书是看不到头的，切片是能立刻看完的。人需要看见完成品才会继续。

## 切片怎么写

一个切片就四段，别多：

1. **一个具体场景开头**（不加背景介绍）："缸是那天下午发的。"
2. **当时的原话**，直接引，不改腔
3. **一个细节**：数字、气味、天气、价钱、谁说了什么
4. **一句当时不知道、现在才知道的话**（可选，没有就不写）

切片不写总结句。**不要在结尾升华**——那是表演腔和教训腔的入口。

## 情绪上来的时候

讲到某件事突然停了、语气变了、开始说"算了不说了"：

- 不追问，说一句"这段先放着"
- 不当场记录情绪，事后补一句"说到这儿停了很久"
- 下次由本人决定讲不讲。**不讲是完全正当的选择**

## 录音与隐私

- 录音前问一句，不同意就不录，打字照样能干
- 录音文件放本地，别随手传网盘
- 涉及他人的内容，成稿前过一遍主文件"底线"第 3 条
