# 岁月锚 · 通用规则与锚库

## 什么是合格的锚

一条锚 = 事件 + 年份或年龄，二者有其一即可入表，两条都有最稳。

**合格**：

- "二〇〇八年高考，考完下大雨" —— 事件 + 年份
- "第一份工作在杭州，干了两年零四个月" —— 事件 + 时长（可算终止年）
- "结婚那年二十六" —— 事件 + 年龄（可反推出生年）
- "搬来这个城市那年，孩子刚上幼儿园" —— 事件 + 他人年龄（可反推）

**不合格**（先记下来，不入表，等后面的素材补上再说）：

- "前几年" "那会儿" "年轻的时候" —— 没有坐标
- "大概是一几年吧" —— 孤立模糊年份，需要另一条锚拴住
- "工作以后" —— 区间模糊，追问"哪一年入职的"

## 通用人生节点锚库

普通人的锚不靠年代大事，靠**制度性节点**——上学、入职、搬家、结婚、生育，这些事件自带年份，而且几乎人人都有。照下面清单收，一次能收一大把。

**求学**
入学、小升初、中考、高考、大学报到、毕业、考研/复读、第一次住校、转学

**工作**
第一份工作（入职年月）、第一次跳槽、第一次被裁/公司倒闭、第一次带人、第一次涨薪、转行、创业/关张、远程办公开始、现在的这份工作从哪天起

**迁徙·居住**
第一次离家、第一次租房（哪个小区）、搬家、换城市（哪年、因为什么）、买房、装修、还完房贷、合租的室友

**关系**
初恋、在一起、分手、结婚、离婚、生孩子（每个孩子的出生年月）、父母生病/住院/离世、最好的朋友是哪年认识的、养的第一只宠物

**身体**
第一次住院、手术、体检第一次查出问题、戒掉什么（烟/酒/熬夜）、开始锻炼、体重最重/最轻的那年

**钱**
第一笔工资（多少）、第一次大额支出、第一次负债、还清债务、第一次给父母钱

**技术与物件**
第一部手机、第一台电脑、第一次上网、注册第一个社交账号、第一次坐飞机、第一次出国、换过的手机号

**标记法**：收锚时不写"童年很苦"这种判断，只写"一九九五年 上小学，走四十分钟山路"。判断留给成稿，锚只负责钉时间。

## 校验：锚与锚互相对表

核心是**出生年**。每条带年龄的锚都能算出一个出生年，全体锚算出的出生年应当一致：

```
锚"高考那年十八" + 高考年 2008 → 出生 1990
锚"生老大那年二十八" + 老大出生 2018 → 出生 1990  ✓ 一致
锚"第一份工作二十二岁" + 入职 2015 → 出生 1993  ✗ 差 3 岁，标【对不上】
```

判定：

- 各锚推得出生年误差 ≤1 岁 → 通过，取众数
- 误差 ≥2 岁 → 标【对不上】，**不裁决谁对**，把两条锚对应的事摆在一起问先后。人记不准"哪一年"，但几乎总能答对"哪件在前"——用先后顺序修正年份
- 与旁证冲突（合同日期、毕业证、结婚证、照片 EXIF）时，**以本人所述为准记录，旁证括号附注**："二〇一〇年入职（合同为二〇一一年三月）"。这本书记的是记忆，不是档案

## 年代量级参照（只用于校验，绝不用来生成）

有时候两条锚都对不上，需要判断"这个年份有没有可能"。下面这张表就是干这个用的。

**用途只有一条：发现不可能，然后回去再问一遍。**
**用途不包括：替他补细节、纠正他的说法、把大概说成确定。**

### 学制与年龄（用来反推出生年）

| 情形 | 大致规律 |
|---|---|
| 七岁上学（多数地区） | 小学 5 或 6 年 + 初中 3 年 + 高中 3 年 → **高考年 ≈ 出生年 + 18** |
| 六岁上学（城市较常见） | 高考年 ≈ 出生年 + 17 |
| 五三制（小学五年、初中三年，部分地区八九十年代） | 高考年 ≈ 出生年 + 17 |
| 初中毕业上中专/技校/务工 | 出门年 ≈ 出生年 + 15 或 16 |
| 复读一年 | 高考年比同龄人晚 1 年，属常见，不是矛盾 |

**用法**：他说"九七年高考"，出生年就该在一九七九年前后。差三年以上，就是某条锚记歪了。

### 事件年份（用来判断"那时候有没有这东西"）

大致量级，不必精确到年：

| 事物 | 出现的年代 |
|---|---|
| 粮票、布票 | 一九九三年前后陆续取消 |
| 大哥大 | 九十年代前期，极少数人 |
| BP 机、寻呼台 | 九十年代中后期 |
| 福利分房终止（房改） | 一九九八年前后 |
| 下岗潮 | 九十年代末 |
| 高校扩招 | 一九九九年开始 |
| 大学并轨收费（学费明显上涨） | 九十年代中后期起，各地不同 |
| 网吧、拨号上网 | 九十年代末到二〇〇〇年代初 |
| 小灵通 | 二〇〇〇年代初 |
| 手机号升到 11 位 | 一九九九年前后 |
| 淘宝 | 二〇〇三年起 |
| 支付宝 | 二〇〇〇年代中 |
| 智能手机普及 | 二〇一一年前后 |
| 微信 | 二〇一一年起 |
| 微信支付 / 扫码付款 | 二〇一三到二〇一四年起普及 |
| 网约车 | 二〇一三到二〇一五年 |
| 外卖平台大战 | 二〇一四到二〇一六年 |
| 共享单车 | 二〇一六到二〇一七年 |
| 义务教育免学杂费（农村） | 二〇〇六年起 |
| 独生子女政策 | 一九八〇到二〇一五年 |
| 二孩、三孩政策 | 二〇一六年、二〇二一年 |

**用法示例**：他说"二〇〇五年在厂里用微信给我老婆发消息"——微信二〇一一年才有。这不是撒谎，是年份记早了七八年。这时**不要点破**，用一个能定年的问题绕过去："那会儿你用的是诺基亚还是别的？"手机型号比年份好记，一句话就能把年份拉回来。

### 钱的量级（用来判断数字有没有离谱）

只能给量级，别当准数：

| 时期 | 城镇普通月工资量级 | 一碗面的量级 |
|---|---|---|
| 一九九〇年前后 | 一两百元 | 一两元 |
| 二〇〇〇年前后 | 七八百元 | 三四元 |
| 二〇一〇年前后 | 两三千元 | 八到十元 |
| 二〇二〇年前后 | 六七千元 | 十五到二十元 |

**用法**：他说"二〇〇三年第一个月工资八百六"——完全在量级内，可信。他说"二〇〇三年工资八千"——要么记错了，要么那是年终奖或一整年的数，值得再问一句"是月还是年"。

### 三条禁止

1. **不拿参照补细节。** 表里写的是"普遍情况"，不是他的情况。不能因为"那个年代都这样"就替他写。
2. **不用参照纠正感受。** 他说"那年穷得吃不上饭"，就算当年物价很低，那也是他的感受，不改。
3. **参照只用来提出问题，不用来下结论。** 用它发现疑点，再回去问他；不要用它写出一个他没说过的年份。

> 这张表唯一的合法输出是一个**新问题**。永远不是一个结论。

## 反推：一条锚带出一串年份

锚钉住后，主动要"锚上的挂件"：

- 工作锚 → 每次跳槽的年份、每段待了多久
- 迁徙锚 → 每次搬家的"城市 + 小区 + 年份"。**住址序列是最扎实的骨架**，比年份好记
- 生育锚 → 孩子出生年、当时住哪、谁在医院陪的
- 关系锚 → 认识年、在一起年、分开年

孩子出生年、入职年月、搬家年份，这三组最硬，先收齐，时间线就立住了。

## 缺口

时间线按**五年一段**分（普通人 25–45 岁事件最密，十年会糊成一片）。检查三件事：

1. **空段**：五年里一条锚都没有。16 岁以后的空段算**缺口**，进补缺清单；16 岁以前的空段标**可选**——多数人童年记忆本来就稀，不该当成欠账。
2. **薄段**：只有一条锚，而这五年恰是人生大段（上大学、职业起步、生育期）。列观察项，后面顺带问，不单独立项。
3. **回避段**：某段反复被跳过——问东答西、听完就岔开。**不追。** 记一句"此处暂不展开"，留到你想说的时候。有些事不说，是选择。

## 缺口怎么出题

不要问"那几年发生了什么"——这种问题会逼人现编。缺口按**四样东西**出题，每一样都能落到具体：

1. **住在哪** —— 哪座城市、哪个小区、几楼、朝哪边、房租多少
2. **吃什么** —— 常去哪家店、谁做饭、有没有一道菜现在还想
3. **每天走哪条路** —— 通勤怎么走、多远、路上听什么
4. **身边有谁** —— 当时跟谁最常来往、同事几个、有没有人后来失联了

四样里只要有一样肯讲，锚就来了，其余三样会跟着出来。

## 记不清的处理

见主文件"记不清的三档处理"。这里只补三条判定：

- 同一件事讲出两个以上版本，**两个都留**，标〔两说〕，不要挑一个写成定论
- 年份反复变化（"一四年？一五年？"），**写成区间 + 不确定**："大概是一四到一五年间"
- 自己说"记不清了"，**就此打住**，不换角度再问三遍
