# 素材先行 · 三级素材库与题库

## 为什么先翻再问

空口问"你还记得那年吗"，得到的多是概括。手里拿着东西问"这张照片怎么回事"，得到的是细节。

原因不神秘：**回忆是被线索勾出来的，不是被问题逼出来的。** 线索越具体，勾出来的越具体。相册、订单、聊天记录就是最好的线索——它们有日期、有地点、有别人说的话，全是记忆缺的那一半。

原则一条：**先翻到，再开口。问题挂在素材上，素材不在，那个问题就别问。**

## 一级 · 手机相册

最富的一级，也最常被忽略。十年相册等于十年的旁观视角——别人给你拍的、你在哪、穿的什么、胖了还是瘦了。

**怎么翻**

1. 按年份筛，每年挑 12 张（每月一张，或按地点聚合后的代表照）
2. 优先挑**你自己在里面**的照片——那是别人眼里的你
3. 挑三类：**平时不会翻到的**（不是风景大片、不是精心摆拍的）、**有别人的**、**拍糊了的**（拍糊的往往是被抓拍的那一刻）
4. 看照片的元数据：日期、地点、连拍的一组里前后的照片

**问什么**

- 这张是谁给你拍的？他当时在哪？
- 这是哪个季节？你穿的这件衣服，后来还留着吗？
- 拍完这张之后，你们去干什么了？
- 这张里的那个人，现在还有联系吗？
- 这地方现在是什么样了？你去过第二次吗？
- 这张为什么留下来了？当时觉得好看，还是忘了删？

**连拍组的特殊用法**：一组连拍里，最后一张往往是笑场或散场——那才是那天真实的结尾。

## 二级 · 数字痕迹

手机里有你生活的原始台账，而且**能搜**。想不起哪年住哪，翻一次外卖地址就行。

### 聊天记录

- 搜年份关键词（"2017"）、搜地址（小区名）、搜"辞职""搬家""分手""结婚"
- 找最早的那批记录：谁是你微信里第一个说话的人？
- 问：这个群现在还在吗？你们当时为什么建这个群？

### 订单与账单

外卖、打车、机票火车票、淘宝、京东、房租转账、水电缴费。

- 第一笔外卖订单是哪年？什么店？
- 打车记录里最常出现的地址是哪几个？（→ 住址序列、常去的地方）
- 有没有一笔转账现在看特别刺眼——给谁、为什么？
- 买过最后悔的东西是什么？当时为什么想买？

### 社交平台历史

朋友圈、微博、小红书、豆瓣标记、QQ 空间。

- 翻到自己最早的一条——那年在想什么？
- 有没有一条发完就删了、或者设置了仅自己可见的？那条是什么？
- 有没有一条现在看觉得"这不像我写的"？

### 听歌与观影

音乐年度报告、影单、游戏时长。

- 某一年你循环最多的是哪首？那年发生了什么？
- 有没有一首歌，现在听还是不敢听/还想听？
- 看过的片子里，哪一部是你和别人一起看的，现在还记得那天？

### 位置与足迹

导航历史、打车记录的常去地、运动 App 的轨迹、地图软件的"我的足迹"。

- 通勤那条路，现在还记得几个红绿灯？
- 有没有一个地方，你去过很多次但说不上为什么？

## 三级 · 实体物件

有就留着，没有不必强求。**不必为了写书去找物件**——这一级是补充，不是前提。

**能想到的都算**：工牌、火车票、租房合同、毕业证、体检单、工资条、笔记本、旧手机、旧钱包、钥匙扣、票根、信件、贺卡、奖状、离职证明、诊断书。

**问什么**

- 这个东西是哪年拿到的？当时谁给的？
- 它为什么一直留着？（这条问题最出东西）
- 上面有磨损、字迹、贴纸吗？是谁弄的？
- 如果现在要扔掉它，你会犹豫吗？

## 附 · 到底去哪儿翻（操作手册）

上面说的是"翻什么"，这里是"在哪翻"。都是手机和电脑上现成的功能，不需要任何工具。

### 按问题找来源

| 你想知道 | 去哪儿翻 | 备注 |
|---|---|---|
| 某年住在哪个小区 | **外卖 App 的地址簿、淘宝收货地址、打车常用地址** | 三个地址一交叉，住址序列基本能还原 |
| 哪年换的工作 | 社保缴费记录、公积金、**个税 App 的收入明细** | 断缴、换单位的月份一目了然 |
| 哪年去过哪 | **12306 订单、航旅纵横、打车行程、地图"我的足迹"** | 火车票记录通常能查十年以上 |
| 某段时间的情绪 | 音乐年度报告、朋友圈、微博 | 循环最多的那首歌 + 那年的文字，情绪曲线自己会浮出来 |
| 什么时候搬的家 | 房租转账记录、水电缴费、宽带开户 | 比记忆准 |
| 工资变化 | 银行流水、工资条、个税明细 | 精确到月 |
| 学历与证件 | 学信网、毕业证、职业资格证 | 日期绝对可靠 |
| 生病与身体 | 医保消费记录、体检报告、挂号记录 | 哪年住院、哪年开始有问题 |
| 老照片 | iCloud / 各家云相册按年份筛；**老同学的相册** | 后一条最关键，很多人只有别人手里才有自己年轻时的照片 |
| 更早的痕迹 | QQ 空间、人人网、博客、网易相册、贴吧 | 二〇〇五到二〇一二年这段，常常只剩这些 |

### 几个具体入口

- **微信**：我 → 服务 → 钱包 → 账单（可按月翻）；朋友圈 → 我的朋友圈 → 按年滑到最底；聊天记录搜索框里直接搜年份、小区名、"辞职""搬家"
- **支付宝**：我的 → 账单 → 筛选月份；「年度账单」每年一份，是最省事的时间线
- **个税 App**：收入纳税明细，能看到每一家单位、起止月份
- **12306**：我的 → 订单 → 已支付，往前翻能翻到最早那笔
- **地图类 App**：足迹 / 行程回顾，会按年份聚合
- **相册**：iPhone「相簿 → 媒体类型/年份」、安卓各家的「回忆 / 按地点」；搜索框里直接搜"杭州""毕业"

### 翻之前先做一件事

**把要用的东西另存一份出来。** 截图、导出、复制到电脑上单独一个文件夹。

理由有两个：一是这些东西会过期（账单通常只保留几年、旧 App 会下线）；二是**翻的过程会占用很长时间，一次翻完不如分几次，但第二次往往找不到第一次看到的那个位置。**

### 三个提醒

- **只翻你自己的。** 别人的手机、别人的聊天记录，不碰。
- **别在情绪差的时候翻。** 账单和旧照片很伤人，翻到心里发沉就停。
- **翻到的东西不要重新命名、不要整理成"漂亮"的文件夹。** 原始文件名里带日期，那就是证据。

## 素材到锚的转换

翻素材时顺手标锚。看到日期就记一条：

```
2016-04-09  相册 · 杭州拱墅区某小区门口   → 锚：2016 年 4 月搬进拱墅
2017-11     外卖地址改成滨江区            → 锚：2017 年底搬到滨江
2019-03     辞职信的邮件                  → 锚：2019 年 3 月离职
```

这些日期比记忆准，直接进时间线，能让一批模糊的年份归位。

---

## 边界

- **只翻你本人授权的东西。** 别人的手机、别人的聊天记录，不碰。
- 聊天记录里涉及第三人的，用之前先看主文件"底线"第 3 条。
- 素材原文件别覆盖、别重命名、别移动。它们是证据，改了就没了。
- 若某个素材让你情绪明显波动，先停，别硬翻。
