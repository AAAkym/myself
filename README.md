# 我的一辈子 · 人生记录

> 普通人为自己立传的一套方法 + 工具箱。
> 通过跟 AI 持续对话——它负责"拷问"和聊天，你负责回忆——把你这半辈子攒成能读、能打印的东西。

## 它是干什么的

不说"写一本自传"这种大话。它干的事很具体：

- **问你，不问别人。** 讲述者就是传主，你记得什么就写什么。
- **不问"你的人生是怎样的"这种大问题。** 问的是"你小时候住的房子一共几间""你走的那天谁送的你"这种能具体回答的小事。
- **一次只聊一个话题，随时能停。** 二十分钟碎片时间就能聊一场，断了明天接着来。
- **记不清就标"不确定"，绝不替你编。** 这本书的目标是"写得住脚"，不是"写得好听"。

## 怎么工作：四步流程

```
① 立项拷问  →  ② 钉岁月锚  →  ③ 逐话题访谈  →  ④ 攒稿成书
 定边界          立时间线        一次一件事        切片→长文→书
```

**① 立项拷问（一次会话）**
开场六题一轮定清：给谁看、写到哪、真名化名、有多少时间、要什么产物、哪些明确不写。先划禁区，免得写到一半白写。

**② 钉岁月锚（一次会话）**
收 8–15 条"自带年份"的事：高考哪年、第一份工作干了多久、孩子几岁搬的家……每条锚都能反推一批年份，钉完时间线就立起来了，哪里断了哪里就是要补的缺口。

**③ 逐话题访谈（多轮，可异步）**
按"家→上学→出门→立住→扛事→中年→现在"七个阶段从头问到尾，每阶段有现成的问题清单和"必问三题"。聊的时候带素材：相册、聊天记录、外卖地址、订单——它们比记忆老实。

**④ 攒稿（按你走到哪算哪）**

| 产物 | 大小 | 说明 |
|---|---|---|
| 记忆切片 | 几百字 | 一个话题一篇，最小产出，先交这个 |
| 长文 | 三五千字 | 一个阶段合成一篇（如"2013–2017，在杭州"） |
| 书 | 可打印 | 切片长文按时间线织成章，锚密年份厚、锚稀年份薄 |

## 对话的两种节奏

- **决策题**：一次发完，每题带推荐答案，回 `yes` 全接受。
- **回忆题**：一次只问一个，**绝不给答案**——给了暗示你会顺着记错。只允许三种安全的辅助：用你自己的锚算年份、拿照片订单当提示、给中性并列选项。

## 目录结构

```
进度.md              断点文件：边界、已问、待定、素材登记（每次会话先读它）
素材/                翻出来的照片、账单截图、导出文件（原样不改名）
切片/                一次一场的成稿，文件名用日期+地点
长文/                一个阶段合成的三五千字
书/                  目录、排版、打印稿

SKILL.md             完整方法论（给 AI 看的工作手册）
references/          11 份参考文档：访谈题库、拷问协议、追问库、难例手册、成书工艺等
scripts/             两个本地脚本（纯 Python 3 标准库，不联网）
templates/           书版式 HTML，浏览器打开即可打印
```

## 工具脚本

```bash
# 生成时间线、检查缺口
python scripts/anchor_timeline.py --birth 1990 --year "2008:高考" --age "18:高考" --to 2026

# 扫描成稿里的腔调病（标签腔/概括腔/表演腔/教训腔）
python scripts/tone_scan.py 切片/某篇.md
```

## 底线（不会做的事）

- 不编造、不"合理想象"，不补情节、补对话、补心情
- 不替你回忆——只推算、只提示、只列选项
- 不替你总结人生意义，不写盖棺定论
- 你说"这段不写"，就删，不劝第二次
- 写到还在世的人，先问"这段家人看到行吗"，犹豫就匿名化或跳过

## 快速开始

对 AI 说：**"开始我的人生记录"**。
它会先做立项拷问（六题，回 yes 即过），然后钉锚，然后你们就一个一个话题聊下去。
中断多久都没关系——`进度.md` 记得你聊到哪。
